# GDA-004: Checkout Leaves Stale Tracked Files

**Status:** Fixed
**Fix details:** Checkout now compares current index with snapshot and removes entries not present in the target snapshot.

## Problem

`gda checkout <snapshot>` restored symlinks for files in the snapshot, but did not clean up files tracked in the current index that were not present in the snapshot. This left stale symlinks and index entries in a state that didn't match the snapshot.

## Reproduction

```
gda add file1.txt
gda snapshot snap1
gda add file2.txt
gda checkout snap1  # file2.txt still tracked + symlink present
```

## Fix

Before restoring snapshot entries, iterate the current index and remove any path that doesn't exist in the target snapshot (both symlink and index entry).
