# GDA-006: Repository Root Auto-Discovery

**Status:** Open (v2 feature)
**Priority:** Medium

## Problem

All GDA commands assume the repository root is the current working directory. Running `gda status` or `gda add` from a subdirectory will either fail (no `.gda/` found) or silently create a new repo in the wrong place (if run in a fresh directory).

## Expected Behavior

Walk up from the current directory looking for `.gda/`. If found, use that as the repository root. If not found, error (except for `gda init` which creates one).

## Implementation Notes

- Walk up at most 10 levels to avoid infinite loops
- Only search on commands other than `init`
- Cache the resolved root per session
